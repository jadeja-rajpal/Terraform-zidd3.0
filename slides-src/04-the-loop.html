The Terraform loop

Four commands. You will type all of them today.
terraform init
Download the providers
Once per project, and again when you add a new provider.
terraform plan
Preview the changes
Changes nothing. Always read it before you apply.
terraform apply
Do it
Terraform shows the plan again. Type yes to confirm.
terraform destroy
Delete everything
Removes only what this project created.
↻  Edit code → plan → apply. Repeat as often as you like.
How to read a plan
+create
~change in place
-destroy
-/+replace it (destroy, then create)
