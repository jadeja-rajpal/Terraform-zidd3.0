Why Terraform?

The boss wants 3 S3 buckets: dev, stage, prod. Versioned and private.
Console clicking
1S3 → Create bucket  dev
2S3 → Create bucket  stage
3S3 → Create bucket  prod
4Open each one → turn on versioning  × 3
5Open each one → block public access  × 3
Dozens of clicks. Missed a checkbox on prod? Nobody knows. Tomorrow: do it all again in the second account.
Terraform
main.tf
resource "aws_s3_bucket" "env" {
  for_each = toset(["dev", "stage", "prod"])
  bucket   = "${var.prefix}-${each.key}"
}
terraform apply

versioned, private
