Terraform in One Shot
@devops_jadeja

One module, three environments

Each folder has its own state, so a change in dev cannot touch prod.
folders
work/
├── modules/
│   └── secure-bucket/   ← written once
└── environments/
    ├── dev/     ← state: dev/terraform.tfstate
    ├── stage/   ← state: stage/terraform.tfstate
    └── prod/    ← state: prod/terraform.tfstate
dev/main.tf
module "app_bucket" {
  source      = "../../modules/secure-bucket"
  bucket_name = "jadeja-dev-app-tf-demo"
}
sourceup two folders, into modules
bucket_namea different name per environment
